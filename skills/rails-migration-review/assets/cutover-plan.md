# 維護窗口與切換計畫

## 開放前確認

- [ ] 寫入控制、在途工作與事件處理有證據。
- [ ] 最終資料在約定邊界內，驗證達到預定範圍。
- [ ] 工作與排程權責明確，不會跨環境重複執行。
- [ ] 本階段需更新的憑證已由實際使用端驗證；其餘輪替與撤銷項目有明確時程。
- [ ] 目標新寫入後的回復方式可行，或已明確採用在目標修復。
- [ ] 驗收角色與觀察方式已就緒。
